# Canva AI Poster Blog Page

Files:
- index.html — blog page with SEO meta tags and Google Translate
- css/style.css — minimal custom CSS
- js/script.js — small JavaScript enhancement

## Setup

1. Keep the folder structure unchanged.
2. Replace `https://example.com/how-to-create-social-media-posters-using-canva-ai`
   with the actual canonical URL.
3. Replace `Your Name` with the website/blog author.
4. Upload the files to your hosting.

The page uses Bootstrap 5.3 from jsDelivr and Google's Website Translator widget.
